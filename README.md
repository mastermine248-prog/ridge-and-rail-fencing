# Ridge & Rail

A static demo website for a fictional Australian fencing, decking and pergola business.

Open `index.html` or serve this directory with any static web server. There is no build step.

The photographs and before/after projects are illustrative generated concepts. Testimonials, prices, and the business identity are demo content. The quote form previews information locally and does not transmit enquiries.

## Pages

- `/` — home, project comparisons, testimonials, pricing and quote brief
- `/services/fencing.html` — fencing planning guide
- `/services/decking.html` — decking planning guide
- `/services/pergolas.html` — pergola planning guide

The image generation prompts for the three service hero photos are in [`assets/image-prompts.md`](assets/image-prompts.md).
